# Guía de estilo · Linear-inspired (Alex)

Dirección visual tomada del estudio de linear.app (nov 2026). No usa logos ni wordmarks de Linear.

## Carácter
Precisión silenciosa / sistema de trabajo. Oscuro, jerarquía por grises y hairlines, tipografía Inter ajustada. Menos “plataforma expansiva”, más herramienta enfocada.

## Color
| Uso | Valor |
|---|---|
| Fondo | `#08090a` |
| Superficie | `#121315` |
| Texto | `#f1f2f3` |
| Secundario | `#9298a1` (mín. para cuerpo esencial; no usar grises más tenues) |
| Bordes | `rgba(255,255,255,.09)` |
| CTA primario | blanco sobre negro |
| Acento | plata/gris claro, no índigo Stripe |

## Tipografía
Inter (variable). Títulos ~550–600, tracking −0.035em. Etiquetas monoespaciadas pequeñas para eyebrows.

## Motivos
Filas con divisores, cards en rejilla con bordes compartidos (no flotantes), un solo halo neutro detrás del hero, botones píldora. Sin mesh gradient Stripe.

## CV A4
Papel blanco, cabecera con filete negro fino, fechas en columna fija ~30 mm, labels de sección mono uppercase. Sin página negra completa.
